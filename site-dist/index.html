Install

Beacon's installers aren't code-signed yet, so your computer will show a security warning the first time.

Windows

  1. Open the downloaded .exe.
  2. If SmartScreen appears, choose More info, then Run anyway.
  3. Approve the administrator prompt and finish the installer.

Mac

  1. Open the .dmg and drag Beacon to Applications.
  2. Open Beacon. If macOS blocks it, go to System Settings, then Privacy & Security, and choose Open Anyway.
  3. Allow local network access when asked.

Before you install

  • Early release. The encryption hasn't been independently reviewed, so don't rely on Beacon for highly confidential data yet.
  • Identity. Anyone on your network running Beacon can join and pick any name. Check the device ID before sharing anything sensitive.
  • Automatic downloads. Files and folders sent to you save automatically and are never opened for you. You can turn this off in Settings, and should be careful opening files you weren't expecting.
  • Saved data. Chat history is stored unencrypted on each computer, except password-locked messages.
  • Network access. Beacon needs UDP port 24250 and TCP port 24251. Guest Wi-Fi often blocks this kind of traffic.
  • Updates. From version 0.3.0, Beacon downloads new versions itself and asks you to restart. On Windows, each update also shows an administrator prompt.
